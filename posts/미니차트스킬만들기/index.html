직전 글 KRX거래시간연장을 쓸 때 차트가 필요해서 그냥 GPT6-astra에게 만들어 달라고 했는데 꽤 괜찮았다. “~한 차트를 그릴거야 만들어줘” 해서 만든 것이다.

그런데 차트를 추가하다 보니 글 안의 소스가 너무 많아졌다. 차트마다 비슷한 코드가 반복되면서 불필요한 중복도 많아졌다. 그래서 GPT가 생성한 차트들의 공통점을 모아서 js미니 라이브러리로 만들고 블로그에 임베딩하게 되었다.

1. 미니차트 라이브러리

주로 꺽은선 직선 그래프외에 다른 차트를 쓸일이 있겠지 싶다. 가장 효과적이고 또 나도 자주 사용하므로 이 차트 위주로 GPT에게 부탁했다. 사실 원샷에 나온것은 아니고 요청을 몇번 더 하여 맞춘 것이다.

HTML
<div class="mini-chart">
<script type="application/json">
{
  "type": "line",
  "title": "오류율 추이",
  "labels": ["1주", "2주", "3주", "4주", "5주"],
  "unit": "%",
  "y": { "min": 0, "max": 10, "step": 2 },
  "series": [
    {
      "name": "실적 (예시)",
      "values": [8, 6, 4.5, 4.5, 4.5]
    },
    {
      "name": "예상 (예시)",
      "values": [null, null, 4.5, 3.8, 3.1],
      "style": "dashed",
      "fill": "gradient"
    }
  ],
  "annotations": [
    { "type": "y-line", "y": 4.5, "label": "4.5% 기준" },
    {
      "type": "point",
      "x": "5주",
      "series": "예상 (예시)",
      "label": "예상 3.1%",
      "position": "below"
    },
    {
      "type": "point",
      "x": "5주",
      "series": "실적 (예시)",
      "label": "실제 4.5%",
      "position": "above"
    }
  ],
  "caption": "예제 차트) 오류율이 4.5%수렴하는 상황 표현"
}
</script>
</div>

위 처럼 ‘데이터’ 만 만들어놓으면 차트라이브러리가 자동으로 읽어들이고 차트로 렌더링 하게 된다. 중간에 꺽이는 부분은 null을 사용 그리지 않고 있다가 필요한 부분에서 갈라칠때 수치가 있는 부분만 그리게 하여 만들수 있다.

이것도 차트를 렌더링하는 스크립트가 다 빠진 것이라 엄청 간결해진 것이지만 또 어떻게 사용해야하는지를 알아뒀다가 나중에 또 써먹어야 하는데 아직도 json 등으로 복잡하게 구성해야 한다. 이래서 ‘스킬’ 을 사용하여 GPT에게 만들어 달라고 요청하도록 하였다.

2. 스킬 만들기

데이터 포맷을 정했으니 LLM이 이 형식에 맞춰 작성하도록 스킬도 만들어 달라고 했다.

graph LR 자연어요청 --> |AI-Skill|JSON데이터구조 --> |렌더링|차트
TXT
.agents/skills/mini-chart/
├── README.md
├── SKILL.md
└── references/
    ├── format.md
    └── examples.md

2.1. 개발파트 진척률

여러 개발파트의 진척률을 비교하는 예제

TXT
mini-chart 스킬로 여러 개발파트 진척률을 그려줘.
아래는 설명용 예시 데이터이고 단위는 %야.

기간: 5월, 6월, 7월, 8월
프론트엔드: 10, 45, 85, 100
백엔드: 15, 60, 95, 100
데이터: 5, 30, 65, 90
계획: 10, 55, 100, null

파트별로 서로 다른 색의 실선을 사용하고, 계획은 빨간 점선으로 해줘.
Y축은 0~100으로 하고 눈금 간격은 25로 해줘.
7월에는 '개발 목표일' 세로선을 넣어줘.

2.2. 막대그래프

직전 글의 예시 종목별 불균등한 주문분포와 유사한 막대그래프

TXT
mini-chart 스킬로 항목별 주문건수 막대그래프를 그려줘.
아래는 설명용 예시 데이터이고 단위는 건이야.

A: 500, B: 420, C: 300, D: 220
E: 150, F: 100, G: 60, H: 0

A부터 H까지 순서를 유지해줘.
항목 수 기준 상위 25%인 A와 B는 파란색, 나머지는 회색으로 해줘.
A~B 구간에는 옅은 파란 배경과 '상위 25%' 설명을 넣고,
B 오른쪽 끝에는 점선 경계선을 표시해줘.

3. GPT에게 요청

User. KRX거래시간연장.md 파일은 새로운 블로그 글이야 , 여기서 라인차트는 GPT6 도움을 받아서 svg 및 스크립트로 html 엘리먼트로 바로 만든거야 , 그래서 내 생각에 이런 라인차트, 막대차트를 만드는 라이브러리를 블로그에 심고 나는 그냥 데이터부분만 만들어서 블로그 글에 넣으면 되지 않을까 하는데

🤖 ChatGPT:
블로그에 공통 차트 기능을 한 번 넣고, 글에는 데이터만 적는 방향에 동의해요. 지금 글처럼 매번 SVG와 스크립트를 넣으면 글보다 차트 코드가 길어지고, 색이나 글자 크기를 바꿀 때도 차트마다 수정해야 하니까요.

핵심은 글을 쓰는 방식과 차트를 그리는 방식을 분리하는 것이에요.

TXT
블로그 글에 차트 종류·데이터 작성
                ↓
          공통 Shortcode
                ↓
       공통 스타일로 차트 표시

(…생략…)

User. 차트의 스타일은 개발 진척률 같이 하면 좋은데 특별히 점선으로 표현한것 있잖아, “계획진척률” 이나 “예상오류율” 보면 빨간색이나 노란색으로 특이하게 눈에 띄는 형태로 강조를 한거야 , 그래서 라인 차트는 기본은 꺽은선이고 원과 라인 있잖아 , 그리고 선의 색은 3개로 고정하고 돌려가면서 쓰는거지, 하지만 점선을 써야하는 경우는 특이하게 강조색을 넣는거고 , 빨간색과 겨자색? 이렇게 두개로, 일단 기본이 그렇지만 색을 입력하면 입력한 색으로 지정할수 있도록 하는거고

🤖 ChatGPT:
네. 기본 계열은 3색을 순환하는 실선과 원형 점으로, 강조 계열은 빨강·겨자색을 사용하는 점선으로 정리하면 되겠어요. 전체 스타일은 개발 진척률 차트를 기준으로 하고요.

구분 기본 계열 강조 계열
선 꺾은선, 실선 꺾은선, 점선
데이터 지점 원형 점 원형 점을 기본으로 유지
자동 색상 기본 3색 순환 빨강·겨자색 2색 순환
직접 색상 지정 지정한 색 우선 지정한 색 우선

기본 색상과 강조 색상의 순환은 각각 따로 세는 게 자연스럽겠습니다. 중간에 계획진척률을 넣어도 다른 파트들의 색상 순서가 밀리지 않도록요. 직접 색을 지정한 계열도 자동 색상 순서를 소비하지 않는 쪽을 추천해요.

작성 형태는 대략 이렇게 됩니다.

JSON
"series": [
  { "name": "파트 A", "values": [8, 55, 97, 100] },
  { "name": "파트 B", "values": [4, 47, 95, 100] },
  {
    "name": "계획진척률",
    "values": [0, 50, 100, null],
    "style": "dashed"
  },
  {
    "name": "예상오류율",
    "values": [null, 4.5, 3.8, 3.1],
    "style": "dashed",
    "color": "#B58A24"
  }
]

즉, 아무 옵션 없이 데이터를 넣으면 기본 스타일, dashed를 지정하면 점선과 강조색이 함께 적용되고, color를 넣으면 색만 덮어쓰는 방식입니다. 기본 3색의 정확한 색상값은 나중에 개발 진척률 차트와 맞춰 정하면 되겠어요.

User. 그리고 중요한거 하나 있어 , 내가 너한테 “~스킬을 사용해서 차트를 그릴거야” 라고 말할거야 그러면 차트에 그려질 데이터를 만들어줄수 있도록 스킬도 만들어야 해

🤖 ChatGPT:
네. 그러면 차트를 그리는 JS 라이브러리와, 그 라이브러리용 데이터를 작성하는 스킬을 함께 만드는 것까지 범위에 포함하겠습니다.

사용 흐름은 이렇게 됩니다.

TEXT
“○○ 스킬을 사용해서 개발 진척률 차트를 그릴 거야”
 + 원본 데이터 또는 설명
                 ↓
스킬이 차트 종류·데이터·표현 옵션 정리
                 ↓
글에 붙여 넣을 Shortcode 블록 작성
                 ↓
블로그의 JS 라이브러리가 차트 표시

스킬의 역할은 다음과 같아요.

  • 표·숫자·설명을 라이브러리가 받는 데이터 형식으로 변환
  • 라인·막대 중 목적에 맞는 차트 선택
  • 계획·예상 계열의 점선과 강조색 적용
  • 요청에 맞춰 곡선·그라데이션·어노테이션 설정
  • 항목과 값의 개수, null, 색상 및 옵션 유효성 확인
  • 완성된 Shortcode를 제공하거나, 요청한 글에 삽입

여러 문답을 통해서 특징을 다 정하고 만들었다.

4. 후기

AI시대에는 복잡한 js라이브러리 익힐 필요없이 필요하면 그냥 만들어쓴다.

코딩이 AI들이 훨씬 더 잘짜는 상황에서 더 간단한 데이터 등의 정의등은 AI들에게 시키기 너무 좋은 예제이다.

내가 유명한 js차트라이브러리 끌고 왔으면? 라이센스, 사용법 등을 익혀야 한다. 내가 필요로 하는 기능 말고 다른 수없이 많은 기능들을 가지고 다녀야 한다. 그래서 딱 간단하게 내꺼에 맞는 필요한 기능… 이정도는 그냥 만들어쓰자.
