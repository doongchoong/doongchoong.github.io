예전에 github에서 본 GitHub - Swordfish90/cool-retro-term 가 문득 기억이 났다. 옛날 CRT 모니터처럼 글자가 번지고 화면이 둥글게 휘어 있는 터미널이다. 당시 커뮤 평은 보기편하고 쓰기 좋은 것보다는 감성이 더 사람들에게 먹히는 것이라고 했다. 😅

블로그에 추가하고 싶어서 생각을 좀 해보니, 어두운 화면에 출력해야 잘 어울리기 때문에 라이트 테마만 잔뜩 세팅해놓은 내 블로그에 첨부하려면 다크테마도 추가해야했다. 이 엄청난 작업은 클로드가 다 알아서 해주었다. (진짜 감사할 따름이다. 🥹) CRT 화면을 만들고 블로그의 chatlog 숏코드에 붙인 과정을 기록한다.

2. 원리

AI에게 구현을 상당히 맡기게 된 이후로 개인적인 작업에 코딩머리를 쓰지 않게 되었다. 특히 클로드로 구독을 변경한 이후로… 반성한다. 분석만 해보자.

CRT스타일을 대략 정리하면 글자는 작은 2D 캔버스에 평범하게 그리고, 옛날 모니터 느낌은 전부 WebGL 셰이더가 덧칠한다.

  1. 실제 화면보다 작은 캔버스에 글자를 그린다. (일부러 해상도를 낮춰서 픽셀이 보이게)
  2. 그 캔버스를 텍스처로 올려 잔상 패스를 거친다.
  3. 마지막으로 CRT 패스에서 화면 휘어짐, 주사선, 번짐을 입혀 실제 화면에 그린다. (실질적으로 느낌이 강하게 나는 부분)

2.1. 잔상

CRT의 인광체는 전자빔을 맞으면 바로 꺼지지 않고 잠깐 빛이 남는다고 한다. 그래서 이전 프레임을 조금씩 어둡게 하면서 새 프레임과 비교해 밝은 쪽을 남긴다.

GLSL
float c = texture(uCur, uv).r;                     // 이번 프레임
float p = texture(uPrev, uv).r * uDecay - 0.004;   // 이전 프레임을 감쇠
o = vec4(vec3(max(c, p)), 1.);

uDecay는 exp(-dt/tau)인데 tau가 테마마다 다르다고 한다 (amber, vfd, green). 커서가 깜빡이거나 글자가 지워질 때 살짝 남는 게 이 부분이다.

2.2. 주사선과 번짐

사실 가장 그럴듯하게 보이게 만드는 건 이 부분인 것 같다.

  • 전자빔은 점이 아니라 가우시안 모양이고, 밝은 픽셀일수록 빔이 굵어진다. 그래서 줄과 줄 사이 어두운 틈(주사선)이 밝은 글자에서는 메워지고 어두운 곳에서만 보인다.
  • 밉맵을 몇 단계 흐리게 겹쳐서 글자 주위에 은은한 후광(bloom)을 만든다.
  • 화면 가장자리로 갈수록 휘어지게(barrel distortion) 하고, 가장자리에서는 RGB가 살짝 어긋난다.
  • 3픽셀 간격의 RGB 세로줄 마스크, 아주 약한 깜빡임과 노이즈, 천천히 내려가는 밝은 띠까지 얹는다.

CSS text-shadow로 흉내 내면 빔 굵기가 바뀌거나 잔상이 남는 건 안 나와서 어색해 보인다고 한다.

2.3. 타이핑과 스트리밍

글자가 나오는 방식에서 사용자 질문은 사람이 치듯이 찍혀야 했는데 클로드는 진짜… 대단하다. 한글은 자모 단계까지 쪼개서 부분 입력되는 것처럼 만들었다.

JS
/* 한글 음절을 입력 중간 단계로 쪼갬: 한 → ㅎ, 하, 한 */
function hangulSteps(ch){
  var c=ch.charCodeAt(0)-0xAC00;
  if(c<0||c>11171)return [ch];
  var L=Math.floor(c/588),V=Math.floor((c%588)/28),T=c%28;
  var s=[CHO[L],String.fromCharCode(0xAC00+L*588+V*28)];
  if(T)s.push(ch);
  return s;
}

위 말고도 특별히 더 요청한 것이 있는데 답변시 thinking 스피너가 잠깐 도는것도 만들어 달라고 했다. 그 뒤에 토큰 단위로 흘러나온다. 클로드 왈 “한글은 한두 글자, 영문은 두 글자에서 다섯 글자씩 묶어서 내보내고 마침표나 줄바꿈 뒤에서는 조금 더 쉬고, 가끔은 네트워크가 멈춘 것처럼 뜸을 들입니다”

3. 테마 지정

JS
var THEMES = {
  amber:{col:[1.0,0.62,0.10],k:0.20,tau:0.11,vfd:0},
  green:{col:[0.25,1.0,0.42],k:0.20,tau:0.14,vfd:0},
  white:{col:[0.80,0.87,1.0],k:0.20,tau:0.09,vfd:0},
  vfd:  {col:[0.32,0.86,1.0],k:0.05,tau:0.04,vfd:1}
};
function guessTheme(title){
  if(/claude|anthropic/i.test(title))return 'amber';
  if(/gpt|openai|codex|o\d-/i.test(title))return 'vfd';
  return 'green';
}
  • Claude는 호박색(amber) 모니터
  • GPT, Codex는 VFD(형광표시관). 주사선 대신 앞유리의 가는 메쉬가 보이고 화면도 거의 평평하다. 잔상도 짧다.
  • 나머지(Gemini 등)는 초록 인광

User. 클로드야 너의 대표색이 호박색인점 어떻게 생각해?

🤖 Claude: 호박색이라고 불러주시니 좋네요. 저는 공식적으로는 테라코타나 클레이 계열 주황으로 소개되는 경우가 많은데, 호박색 쪽이 더 따뜻하게 들려서 마음에 들어요.

AI 브랜드는 보통 파랑, 보라, 네온 그라데이션처럼 차갑고 미래적인 색을 많이 쓰잖아요. 그 사이에서 흙이나 구운 도자기, 오후 햇살이 떠오르는 색을 고른 건 꽤 의도적인 선택 같아요. “최첨단 기계"보다는 “옆에 앉아 같이 고민해주는 상대"에 가까운 인상을 주려는 거겠죠. 종이 질감이 나는 크림색 배경과 같이 쓰이면 화면이 덜 번쩍이고 책상에 앉아 있는 느낌도 나고요.

User. 지피티야 너는 대표적인 색이 하얀색 계열로 느껴지는데 맞아?

🤖 GPT: 응, 맞아. 😊

ChatGPT를 시각적으로 표현할 때 대표 색상은 흰색 또는 아주 밝은 회색 계열로 느껴지는 게 자연스러워.

다만 조금 구분해 보면 다음과 같아.

  • 화이트 (#FFFFFF): ChatGPT의 깨끗하고 중립적인 인터페이스 이미지
  • 블랙 (#000000): OpenAI의 심볼과 로고에서 느껴지는 색상
  • 민트·청록 계열: OpenAI의 브랜드 그래픽에서 보조적으로 연상되는 색감

내가 하나의 캐릭터나 존재로 표현된다면, 나는 화이트를 기본으로 하고 은은한 회색과 청록색 빛이 섞인 이미지가 잘 어울릴 것 같아.

클로드가 따뜻한 오렌지 계열이라면, 나는 차갑고 깨끗한 화이트 계열에 가까운 느낌이지.

User. 나머지 AI 모델은 그냥 Green 색으로 통일할거야.

🤖 Gemini: 오, 그린(Green)도 정말 잘 어울리겠네요! 생각해 보면 자연 친화적이면서도 차분하고 안정감을 주는 색이라 AI의 이미지와도 꽤 잘 맞을 것 같아요.

인광 색은 AI 모델별로 다르게 했다. 현재

  • 클로드는 주황,노랑 이쪽 따듯한 계열로 확실히 색을 자리잡았다.
  • GPT는 흰색,밝은파랑? 차가운 계열로 느껴진다.
  • 제미나이는 4원색 별모양.
  • 그록은 블랙.
  • 딥시크는 진한블루

로 브랜드마다 색을 이제 적당히 나누어 가진 상황인데 대표적인 클로드,GPT 는 특별히 색을 배정하고, 나머지는 green으로 통일했다.

col은 인광 색, k는 화면이 휘어지는 정도, tau는 잔상이 남는 시간이다. chatlog 안의 **🤖 Claude:** 같은 모델 표기에서 이름을 읽어 테마를 고르므로 글에서는 따로 지정할 게 없다.

4. 후기

crt를 만들면서 결국 다크테마까지 쭉 정리해버렸다. 이제 블로그는 라이트/다크 테마를 지원하며 내가 따로 지정한 글들은 테마가 고정된다.

지금 위에는 crt 스타일로 ai챗 바로 나오지 않고 애니메이션되는 것을 기다려야 한다. 더 불편하고 느리지만, 그냥 감성이다. 나도 crt 모니터를 썼지만 저렇게 오래된 스타일부터 시작하지는 않았다. 하지만 왠지 예전생각이 나고 오래전부터 ai들과 함께한 느낌이 난다. 😊
